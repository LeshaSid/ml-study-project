# ML Study Project

Учебный проект для изучения и демонстрации основных методов машинного обучения. Реализован в виде веб-приложения на Streamlit.

## Возможности

- **Классификация ирисов** – определение вида цветка по длине и ширине чашелистиков и лепестков (KNN).
- **Предсказание стоимости жилья** – оценка стоимости дома на основе данных о районе (линейная регрессия, дерево решений, случайный лес).
- **Кластеризация клиентов** – группировка покупателей торгового центра по доходу и уровню трат (KMeans).
- **Прогнозирование цены акций Spotify** – предсказание цены закрытия на основе исторических данных (линейная регрессия, случайный лес, XGBoost).

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone <url-репозитория>
   cd ml-study-project
   ```

2. Установите зависимости. Рекомендуется использовать `uv` (проект использует `uv.lock`):
   ```bash
   uv sync
   ```
   Или классический `pip`:
   ```bash
   pip install -r requirements.txt
   ```
   (файл `requirements.txt` можно создать из `pyproject.toml` или установить вручную: `streamlit`, `pandas`, `scikit-learn`, `matplotlib`, `xgboost`)

3. Запустите приложение:
   ```bash
   uv run streamlit run main.py
   ```

## Используемые технологии

- Python 3.13+
- Streamlit – веб-интерфейс
- Pandas – обработка данных
- Scikit-learn – ML-модели (KNN, KMeans, линейная регрессия, деревья, случайный лес)
- XGBoost – градиентный бустинг для прогноза акций
- Matplotlib – визуализация кластеров

## Данные

- `Mall_Customers.csv` – 200 записей о клиентах: возраст, доход, оценка трат.
- `World-Stock-Prices-Dataset.csv` – исторические котировки (фильтруются по Spotify).
- Набор данных California Housing загружается автоматически через `sklearn.datasets`.

- Прогноз цены акций Spotify выполнен на 07.07.2025 для демонстрации, реальная цена указана в коде.
